# Classe 40

Plateforme de revision AFM (Bocconi, I semestre 2026/27) : fiches, QCM, flashcards, cheat sheets et echeances.
Fonctionne hors connexion et s'installe sur l'ecran d'accueil du telephone.

## Mise en ligne sur GitHub Pages

1. Creer un depot `classe40` sur github.com.
2. Add file > Upload files, glisser tout le contenu de ce dossier (pas le dossier lui-meme), Commit.
3. Settings > Pages > Source "Deploy from a branch", branche `main`, dossier `/ (root)`, Save.
4. Le site est en ligne apres une a deux minutes a l'adresse `https://<ton-compte>.github.io/classe40/`.

## Sur le telephone

Ouvrir l'adresse une premiere fois avec du reseau, puis
iPhone (Safari) : Partager > Sur l'ecran d'accueil. Android (Chrome) : menu > Installer l'application.
Tout le contenu, fiches PDF comprises, est mis en cache et reste disponible hors connexion.

## Progression

La progression (QCM, fiches vues, flashcards, echeances modifiees) est stockee sur chaque appareil.
Pour passer d'un appareil a l'autre, utiliser Exporter puis Importer dans la barre laterale.

## Mise a jour

Remplacer les fichiers du depot par la nouvelle version. Le telephone recupere la mise a jour a la prochaine ouverture avec du reseau.
