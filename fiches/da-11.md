## 1. Modèles autorégressifs AR(p) et le cas AR(1)

La marche aléatoire et la marche aléatoire avec dérive peuvent être vues comme des modèles de régression (simples) où la variable explicative est la variable expliquée décalée d'un pas. On généralise en considérant plusieurs décalages.

<div class="def"><b>Modèle autorégressif d'ordre p ≥ 1, AR(p) :</b> processus (Yt)t∈T gouverné par Yt = φ0 + φ1Yt−1 + φ2Yt−2 + … + φpYt−p + εt, où φ0, φ1, …, φp sont des paramètres et εt un bruit blanc.</div>

Cas particulier central : le AR(1), Yt = φ0 + φ1Yt−1 + εt.

- Si φ0 = 0 et φ1 = 1 → marche aléatoire ; si φ0 ≠ 0 et φ1 = 1 → marche aléatoire avec dérive.
- Le processus est stationnaire si et seulement si φ1 ∈ (−1, 1). Dans ce cas :

<div class="def"><b>μt = E[Yt] = φ0 / (1 − φ1)</b><br/><b>σ²t = Var[Yt] = σ² / (1 − φ1²)</b><br/><b>ρk,t = Corr[Yt, Yt−k] = φ1^k</b></div>

Remarques sur le AR(1) stationnaire :

- L'autocorrélation φ1^k, puisque |φ1| &lt; 1, décroît quand le lag k augmente. Si φ1 &gt; 0, toutes les autocorrélations restent positives ; si φ1 &lt; 0, elles alternent entre valeurs positives et négatives.
- L'ACF décrit la persistance : si |φ1| est petit, l'effet d'un choc au temps t se réduit vite dans les périodes suivantes.
- La PACF tend à être négligeable, sauf l'autocorrélation partielle d'ordre 1 (égale à φ1).

<div class="example"><b>Les trois autocorrélogrammes du cours (AR(1) stationnaires) :</b><br/>&bull; φ1 = 0,9 : autocorrélations 0,9 ; 0,81 ; 0,729 ; … ; 0,9^k → forte persistance<br/>&bull; φ1 = 0,1 : autocorrélations 0,1 ; 0,01 ; 0,001 ; … ; 0,1^k → persistance très faible<br/>&bull; φ1 = −0,5 : autocorrélations −0,5 ; 0,25 ; −0,125 ; … ; (−0,5)^k → oscillations positives/négatives, décroissant en valeur absolue jusqu'à devenir négligeables</div>

Pour un AR(p) avec p &gt; 1, les fonctions (moyenne, variance, autocorrélations) deviennent plus complexes et ne sont pas données ; on retient seulement les signatures ACF/PACF ci-dessous.

## 2. Signatures ACF/PACF d'un AR

Pour un AR(p) :

- L'ACF décroît en général (de manière exponentielle ou avec un motif sinusoïdal).
- La PACF montre typiquement un dernier pic non négligeable à l'ordre p.

## 3. Modèles moyenne mobile MA(q)

<div class="def"><b>Modèle moyenne mobile d'ordre q, MA(q) :</b> Yt = εt + θ1εt−1 + θ2εt−2 + … + θqεt−q = ∑i=0..q θiεt−i, où εt est un bruit blanc, θi (i = 1, …, q) des paramètres et θ0 = 1. On peut ajouter une constante c à l'équation.</div>

- Yt est donc une moyenne pondérée des εt (au temps courant et passés) : d'où le nom « moyenne mobile ». Ne pas confondre avec la moyenne mobile de la session 9 (outil de lissage) : ici c'est un modèle probabiliste.
- Un MA(q) est stationnaire quels que soient les coefficients et l'ordre q. De plus :

<div class="def"><b>μt = E[Yt] = 0</b><br/><b>σ²t = Var[Yt] = (1 + θ1² + θ2² + … + θq²)σ² = σ²·∑i=0..q θi²</b><br/><b>ρk,t = (∑i=0..q θiθi−k) / (∑i=0..q θi²)</b> (avec θj = 0 pour j &lt; 0)<br/>→ les autocorrélations sont nulles pour k &gt; q</div>

Remarques sur le MA :

- Comme pour les AR, les propriétés (en particulier la persistance) dépendent de l'ordre et des coefficients. La persistance augmente avec l'ordre q, puisque les autocorrélations d'ordre &gt; q sont nulles.
- Pour un MA(1) : ρ1 = θ1/(1 + θ1²) est la seule autocorrélation non nulle. La persistance est d'autant plus forte que |θ1| est proche de 1. Pour θ1 = 0, le processus se réduit à un bruit blanc (persistance nulle) ; pour θ1 = 1, ρ1 atteint son maximum (0,5) ; pour θ1 = −1, son minimum (−0,5).
- La variance (donc la dispersion) augmente avec la valeur absolue de θ1.
- Exemples du cours : séries et autocorrélogrammes de MA(1) avec θ1 = 1 puis θ1 = 5.

## 4. Signatures ACF/PACF d'un MA

Pour un MA(q) :

- L'ACF montre typiquement un dernier pic non négligeable à l'ordre q.
- La PACF tend à décroître (exponentiellement ou avec un motif sinusoïdal).

<div class="key"><b>Must know (moyen mnémotechnique) :</b> par rapport à un autorégressif, dans un moyenne mobile les comportements de l'ACF et de la PACF sont inversés. AR : ACF décroît, PACF coupe après p. MA : ACF coupe après q, PACF décroît.</div>

## 5. Modèles mixtes ARMA(p,q)

<div class="def"><b>Modèle ARMA(p,q) (AutoRegressive Moving Average) :</b> modèle avec une composante autorégressive d'ordre p et une composante moyenne mobile d'ordre q : Yt = φ0 + φ1Yt−1 + … + φpYt−p + θ1εt−1 + … + θqεt−q + εt, où εt est un bruit blanc.</div>

- Grande flexibilité grâce au choix des ordres p et q et des coefficients ; pas nécessairement stationnaire, à cause de la composante autorégressive.

## 6. Modèles intégrés ARIMA(p,d,q) et cas particuliers

<div class="def"><b>Modèle ARIMA(p,d,q) (autoregressive integrated moving average) :</b> généralisation des ARMA. Le « I » désigne une opération d'intégration, inverse de la différentiation : la classe inclut les processus auxquels l'opérateur différence D a été appliqué (éventuellement plusieurs fois), en général pour rendre la composante autorégressive stationnaire.</div>

- Par exemple, un ARIMA(3,1,2) correspond à un processus qui, après une différenciation, donne un ARMA(3,2).
- Équation générale : Y't = φ0 + φ1Y't−1 + … + φpY't−p + θ1εt−1 + … + θqεt−q + εt, où Y't est la série différenciée d fois, Y't = D^d(Yt).
- Attention : appliquer l'opérateur différence d fois n'est pas une différence d'ordre d ; c'est (pour d = 2) la différence de la différence.

En annulant un ou plusieurs ordres p, d, q, on retrouve les cas particuliers :

<div class="key"><b>Must know (cas particuliers) :</b><br/>&bull; ARIMA(p,0,q) = ARMA(p,q) ; ARIMA(p,0,0) = AR(p) ; ARIMA(0,0,q) = MA(q)<br/>&bull; ARIMA(0,0,0) (avec φ0 = 0) = bruit blanc<br/>&bull; ARIMA(0,1,0) = marche aléatoire (avec dérive si φ0 ≠ 0)</div>

## 7. La démarche de sélection d'un modèle ARIMA

Objectif : trouver le modèle ARIMA qui ajuste le mieux la série donnée.

- **Première étape : identification de l'ordre de différenciation d** (le but est de rendre la série stationnaire). Pas de règle universelle ni de critère absolu : on analyse le graphe de la série (tendance ?) et on mène des tests. En règle générale, on évite les valeurs de d supérieures à 2.
- **Deuxième étape : détermination des ordres p et q.** L'analyse de l'ACF et de la PACF est utile : un (dernier) pic à l'ordre p dans la PACF suggère la valeur p pour la partie autorégressive ; un (dernier) pic à l'ordre q dans l'ACF suggère la valeur q pour la partie moyenne mobile. Ce sont des indications générales, car les deux composantes se chevauchent et s'influencent mutuellement. Il existe aussi des critères statistiques pour déterminer les ordres « optimaux », notamment la minimisation de l'AIC (Akaike Information Criterion), avec un sens analogue à celui des modèles de régression.
- **Troisième étape : estimation des paramètres à partir des données.** Plusieurs méthodes existent ; l'estimation par le maximum de vraisemblance (MLE, Maximum Likelihood Estimation) est particulièrement courante et c'est la méthode par défaut dans de nombreuses fonctions logicielles (dont les fonctions R ci-dessous).
- **Diagnostic final : analyse des résidus**, analogue à celle des modèles de régression linéaire. Le résidu et = yt − ŷt est la différence entre la valeur observée et la valeur prédite (estimée) au même instant. Si le modèle ajuste bien, la série des résidus doit ressembler à un bruit blanc : moyenne environ nulle, variabilité assez constante, autocorrélations pas excessivement élevées. Le graphe des résidus, leurs autocorrélogrammes et les tests appropriés aident à vérifier ces caractéristiques.

## 8. Les fonctions R : arima et auto.arima

- `arima(y, order = c(p,d,q))` (package de base) : estime les paramètres du modèle ARIMA avec les trois ordres fixés (méthode au choix, MLE par défaut). L'option include.mean = TRUE/FALSE détermine si le terme constant est inclus ; par défaut TRUE, sauf si la série est différenciée.
- `auto.arima(y)` (package forecast) : détermine automatiquement le modèle « optimal » en sélectionnant les ordres et en estimant les paramètres selon un critère au choix (par défaut la minimisation de l'AIC). L'option lambda = "auto" applique une transformation de Box-Cox préliminaire si jugée appropriée, avec le paramètre λ choisi automatiquement.
- arima et auto.arima permettent aussi d'inclure et d'estimer une éventuelle composante saisonnière, ce qui mène aux modèles SARIMA.
- auto.arima utilise des procédures efficaces de sélection, mais rien ne garantit que le modèle obtenu soit satisfaisant : un contrôle (par exemple par l'analyse des résidus) et une comparaison avec d'autres modèles sont toujours recommandés.

## 9. Exemple : l'ETF Invesco QQQ

<div class="example"><b>Application de auto.arima à la série des cours de clôture quotidiens de l'ETF Invesco QQQ</b>, du 3 janvier 2007 au 7 juin 2024 (source Yahoo Finance), avec l'option lambda = "auto" :<br/><b>Sortie R :</b> Series: y — ARIMA(1,1,0) with drift — Box Cox transformation: lambda = 0,0988. Coefficients : ar1 = −0,0888 (s.e. 0,0150), drift = 9.10−4 (s.e. 3.10−4). sigma^2 = 0,0004955 ; log likelihood = 10471,09 ; AIC = −20936,19.</div>

- Lecture : la procédure automatique (avec la transformation) a sélectionné un ARIMA(1,1,0) avec dérive : après une différenciation de la série transformée, un AR(1) avec terme constant a été estimé. La sortie donne aussi la variance estimée du bruit blanc sous-jacent, le logarithme de la vraisemblance maximale et l'AIC.
- Le graphe des résidus (`plot(mod$residuals)`) confirme l'adéquation : la série des résidus semble présenter les caractéristiques d'un bruit blanc. L'autocorrélogramme des résidus confirme une structure de corrélation proche de celle d'un bruit blanc (quelques autocorrélations légèrement non négligeables persistent souvent sans conduire à rejeter le modèle).

## 10. Tests de stationnarité (ADF) et de Ljung-Box

<div class="def"><b>Tests de Dickey-Fuller et de Dickey-Fuller augmenté (ADF) :</b> vérifient si une série peut raisonnablement être vue comme une réalisation finie d'un processus (faiblement) stationnaire. Hypothèse nulle H0 : processus non stationnaire ; hypothèse alternative H1 : processus stationnaire. Rejeter H0 fournit une évidence statistique de stationnarité.</div>

- En R : `adf.test(y)`, fonction du package tseries.
- Sur les résidus de l'exemple QQQ : `adf.test(mod$residuals)` donne Dickey-Fuller = −16,122, p-value = 0,01 → H0 rejetée (au niveau 0,01), donc évidence de stationnarité. (Message d'avertissement classique : la vraie p-value est plus petite que celle affichée.)

<div class="def"><b>Test de Ljung-Box :</b> teste l'hypothèse nulle selon laquelle toutes les autocorrélations jusqu'à un certain ordre k sont nulles. Utile, lui aussi, pour le diagnostic des résidus.</div>

- En R : `Box.test(x, lag = k, type = "Ljung-Box")`.
- Sur les résidus QQQ : avec lag = 3, X-squared = 0,51775, p-value = 0,915 → H0 non rejetée ; avec lag = 10, X-squared = 54,812, p-value = 3,4.10−8 → H0 rejetée. Cohérent avec l'autocorrélogramme des résidus, où quelques autocorrélations significatives subsistaient.

## 11. Erreurs fréquentes et pièges d'examen

- Inverser les signatures : AR → PACF coupe après p (ACF décroît) ; MA → ACF coupe après q (PACF décroît). C'est le piège classique de la session.
- Écrire que le AR(1) est stationnaire pour tout φ1 : il faut |φ1| &lt; 1 ; φ1 = 1 donne une marche aléatoire.
- Appliquer la condition de stationnarité du AR(1) au MA(q) : un MA(q) est stationnaire quels que soient ses coefficients.
- Confondre « différencier d fois » et « différence d'ordre d » : D²y = D(Dy), pas yt − yt−2.
- Conclure « non stationnaire » quand le test ADF ne rejette pas H0 : H0 est la non-stationnarité, donc rejeter H0 = évidence de stationnarité. Le sens est inversé par rapport à la plupart des tests.
- Oublier que le Ljung-Box dépend du lag choisi : le même résidu peut passer à lag = 3 et échouer à lag = 10 (exemple du cours).
- Croire que auto.arima garantit un bon modèle : toujours vérifier les résidus et comparer avec d'autres modèles.
- Chercher une moyenne non nulle dans un MA(q) sans constante : μt = 0.
- Confondre le MA(q) probabiliste avec la moyenne mobile de lissage de la session 9.

## 12. À connaître absolument

<div class="key"><b>Must know :</b><br/>&bull; AR(p) : Yt = φ0 + ∑φiYt−i + εt. AR(1) stationnaire ssi |φ1| &lt; 1 ; alors μ = φ0/(1−φ1), σ²Y = σ²/(1−φ1²), ρk = φ1^k<br/>&bull; MA(q) : Yt = ∑i=0..q θiεt−i (θ0 = 1) ; toujours stationnaire ; ρk = 0 pour k &gt; q. MA(1) : ρ1 = θ1/(1+θ1²) ∈ [−0,5 ; 0,5]<br/>&bull; Signatures : AR → ACF décroît + PACF coupe après p ; MA → ACF coupe après q + PACF décroît<br/>&bull; ARMA(p,q) = AR + MA ; ARIMA(p,d,q) = ARMA sur la série différenciée d fois. ARIMA(0,1,0) = marche aléatoire ; ARIMA(0,0,0) = bruit blanc<br/>&bull; Sélection : 1) choisir d (graphe + tests, d ≤ 2) ; 2) choisir p, q (pics PACF/ACF, AIC) ; 3) estimer (MLE) ; 4) diagnostic : résidus ≈ bruit blanc<br/>&bull; R : arima(y, order = c(p,d,q)) ; auto.arima(y, lambda = "auto") ; adf.test (H0 = non stationnaire) ; Box.test(x, lag, type = "Ljung-Box") (H0 = autocorrélations nulles jusqu'au lag k)</div>

## Points de vigilance

<div class="watch"><b>Watch out :</b> le test ADF a pour hypothèse nulle la non-stationnarité : rejeter H0 est une bonne nouvelle (évidence de stationnarité). Ne pas inverser la conclusion.</div>

<div class="watch"><b>Watch out :</b> ρ1 d'un MA(1) ne peut jamais dépasser 0,5 en valeur absolue (maximum en θ1 = 1, minimum −0,5 en θ1 = −1) : si un calcul donne une valeur plus grande, il est faux.</div>
